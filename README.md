# Vellum

**Vellum** — это современный, быстрый и легкий двухпанельный файловый менеджер, построенный на связке Go (бэкенд) и React (фронтенд) с использованием фреймворка Wails. Программа сочетает в себе классический удобный интерфейс в стиле "Total Commander" и современные веб-технологии.

![Vellum Logo](build/appicon.png)

## ✨ Ключевые возможности

*   🚀 **Высокая производительность:** Умное кэширование списков файлов и оптимизированные алгоритмы копирования позволяют мгновенно работать даже с огромными директориями.
*   🌐 **Встроенный SFTP-клиент:** Полноценная работа с удаленными серверами. Поддержка профилей, SSH-ключей и безопасных соединений.
*   🌓 **Темная и светлая темы:** Интерфейс, который бережет ваше зрение.
*   🔤 **Гибкая настройка:** Возможность менять шрифты и их размеры прямо в настройках приложения.
*   ⏳ **Фоновые операции:** Копирование, перемещение и удаление файлов не блокируют интерфейс. Следите за прогрессом через наглядные индикаторы.
*   📦 **Портативность:** Приложение поставляется в виде одного исполняемого файла и не требует установки.

## ⌨️ Горячие клавиши

| Клавиша | Действие |
| :--- | :--- |
| **F3** | Быстрый просмотр файла |
| **F4** | Редактировать (открыть во внешнем приложении) |
| **F5** | Копировать выделенное на соседнюю панель |
| **F6** | Переместить на соседнюю панель |
| **F7** | Создать новую папку |
| **F8** | Удалить (с подтверждением или без) |
| **F9** | Меню SFTP-соединений |
| **F10 / Ctrl+Q** | Выход из программы |
| **Tab** | Переключение между панелями |
| **Backspace** | На уровень вверх |
| **Ctrl + H** | Показать/скрыть скрытые файлы |
| **Ctrl + D** | Закладки |
| **Ctrl + F** | Поиск файлов |
| **Ctrl + ,** | Настройки |

## 🚀 Как пользоваться

1.  Скачайте актуальную версию `Vellum.exe` со страницы [Releases](https://github.com/Shveepss/Vellum/releases).
2.  Запустите файл. Программа автоматически создаст папку настроек в вашем домашнем каталоге (`~/.vellum`).
3.  Для работы с серверами нажмите **F9** и создайте профиль подключения.
4.  Программа сама уведомит вас, если выйдет новая версия.

## 🛠 Сборка из исходников (для разработчиков)

Если вы хотите собрать программу самостоятельно, вам потребуются:
*   **Go** (1.21+)
*   **Node.js** (18+) & npm
*   **Wails CLI** (`go install github.com/wailsapp/wails/v2/cmd/wails@latest`)

### Команды:

```bash
# Режим разработки (с Hot Reload)
wails dev

# Финальная сборка под вашу ОС
wails build
```
